# Resumos Git e GitHub

Este repositório reúne minhas anotações iniciais sobre Git, organizadas e reescritas a partir de videoaulas que assisti e complementadas com observações próprias durante meus estudos e práticas. O objetivo deste material é servir como um guia rápido para consulta, registrando comandos, conceitos e exemplos que me ajudaram a entender melhor o funcionamento do Git no dia a dia. 

[Documentação do Git]: https://git-scm.com/docs
[Documentação do GitHub]: https://docs.github.com/pt
